# Perubahan

- Informasi “Jumlah dipohon” dibuang daripada panel admin, keputusan kelulusan, papan pemuka dan riwayat permohonan.
- Medan had kredit admin tidak lagi diisi secara automatik daripada jumlah dipohon lama.
- Gaji bulanan, had kredit diluluskan dan jumlah pencairan/bayaran dikekalkan.
- Tarikh dan masa mengikuti zon waktu peranti/pelayar pengguna; tidak lagi dikunci ke waktu Malaysia.
- Tiada perubahan struktur pangkalan data; medan lama dikekalkan untuk keserasian.
- Fail .env, metadata Git, dependencies dan hasil build tidak disertakan. Gunakan konfigurasi persekitaran pemasangan sedia ada.

Pengesahan: ujian pemformatan masa dalam zon Jakarta, Malaysia dan New York dan peraturan permohonan lulus. Aliran kelulusan dengan akaun admin sebenar tidak diuji dalam sandbox ini.
